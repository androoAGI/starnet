## Source conclusions

- The shared classifier parses with WHATWG URL before policy checks; normalizes comparison names, root dots and IPv6 forms; classifies embedded IPv4 addresses; and refuses malformed or mixed public/private DNS answers before dialing. The approved public/blocked range distinctions remain explicit data. DNS errors cannot become verified destinations.
- Destinations are privately minted, frozen and carry immutable address facts. The URL getter does not permit retargeting. The pinned lookup answers only the validated host/list, supports `all:true` and family selection, and does not resolve again. Both npm and bundled-fetch consumers retain Host/SNI. Production callers do not supply the static `lookup:null` test escape.
- Web fetch/request resolves each manual redirect and pins that hop's answer. The optional authenticated URL passed to `fetchPinned` must keep the validated origin. Actual secret-substituted headers, authorization/cookie/API-key headers are stripped on scheme/host/port changes; host-added query authentication is not reapplied to later hops. Stored secrets are not accepted as body placeholders. Outside responses retain redaction/fencing and redirect refusals do not receive the host-authored taint exemption.
- Merged paid web search still obtains the exact key/endpoint pair from `credential-store.webRung`, excludes StarNet-credit runs, and registers the existing live key-removal watch. The rung sends to its saved endpoint, rather than silently moving a proxy credential to the public provider. This configured-provider transport remains outside the model-selected public URL classifier as specified.
- The real Chromium launcher installs the validating owned proxy and disables Chromium's loopback proxy bypass. HTTP, CONNECT and WebSocket routes validate before dialing. CONNECT preserves end-to-end TLS. Delayed DNS completion checks owner/client shutdown before opening an upstream; cleanup destroys only the proxy's own agent/sockets. Explicit owned local development origins remain separate from ordinary public navigation. This does not claim to sandbox an external user browser or every non-HTTP browser protocol.
- Connector OAuth's network wrapper enforces public HTTPS without embedded credentials and forces manual redirects. Metadata discovery, DCR and token calls retain their deadline/body ownership; the external authorization-browser URL is prevalidated, not represented as a sidecar-pinned browser session. Successful generic Responses remain available for their legitimate streaming consumers.
- Skill document/package hops use the same strict public-HTTPS boundary. Per-package sessions retain a validated address list and owned dispatcher for a bounded package operation; late resolution after close and foreign-session destinations refuse. Existing package file/path, request, depth, byte and deadline bounds remain intact.
- S4 changes platform descriptions through `runtimeinfo.hostFacts`. The shell rule table preserves the exact prior regexes, order and refusal text; it does not expand shell authority. Catalog construction passes its selected platform to the affected factories and still refuses execution.
