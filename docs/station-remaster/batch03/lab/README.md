# Lab and fabrication source handoff

Six new prop bodies and one separately authored fabricator carriage layer. Source prompts and revision prompts preserve the generation provenance. The wax vat, optical lens and trend pillar are complete source bodies; fabricator and packing robot omit moving parts for new runtime animation layers. Tube glass is empty for a clipped capsule animation.

`native-scale.png` uses the same uniform fit and native footprint bounds as PropRemaster, at four display pixels per world pixel. It is a source geometry proof, not a live saved station screenshot. Machine base aspect ratios are preserved; none are stretched. The chart pillar and robot mast were redrawn to correct initial proportions.

The user-authorized exporter only removes connected neutral background, clears alpha below 16 and crops to the subject. All seven exports preserve subject RGB exactly and have transparent backgrounds; `export-checks.json` contains dimensions, alpha counts and source/output hashes.
