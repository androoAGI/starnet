# Crew illustrated-style repaint

The initial bench calibration responded to the user's rejection of overly photoreal props. After the coordinator found it closer to the workstation, that rendering balance was used as a working assumption for ten further designs. This is not a claim of user visual acceptance. The directory now contains bar, bunk, quarters_pooltable, pokertable, beanbag, stool, industrial_roundtable, sidetable, quarters_minifridge, quarters_vending and the calibrated industrial_bench. Coffee remains coordinator-owned.

Olive cushions now use broad angular painted value planes and seam lines, without weave or fuzz. Wood uses warm painted planes and a few broad marks instead of photographic grain. Dark edge separations and selective highlights preserve legible grown-up game construction. Material diversity, horizontal camera, rear-facing occlusion rail and three feet remain.

Every final original is retained as `{id}-source.png`, with `{id}.prompt.txt`, `{id}.json` native contract and `{id}.export.json` crop/hash/alpha receipt. Every object used one built-in style-transfer call, with its final batch02 identity and revised geometry, workstation rendering reference and the painted bench reference. The pool table specifically uses the clean source, leaving its felt empty for live ball overlays. User-authorized extraction changes alpha/crop only and preserves RGB. All eleven exports have genuine transparent/opaque pixels, no partial alpha and zero RGB changes. Native source and dark-background/native-envelope preview sheets were inspected; holes were separately seeded for beanbag handle, stool, pool-table supports and side-table shelf.

The prior bench shape is preserved: its alpha aspect ratio is approximately4:1, fitting uniformly to width36 and about9px tall inside the existing36x12 envelope, bottom-aligned at y12. Native3x1 footprint, couch-planner claims and rear-rail occlusion remain integration contracts. The stool near rim is now approximately worldy2.788 (target3), feet11; round-table near top rim is approximately worldy3.821 (target4), floor12 and width22.553 of24. These are source landmark/fit measurements, not live character or mount verification. Broad near-square bunk geometry remains. All runtime behavior, animation, bunk quilt/sleeper layering, seating and mounting checks remain owner work; no runtime/shared-manifest/mirror edits or full app test claims were made here.
