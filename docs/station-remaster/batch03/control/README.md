All use the corrected broad painted 2D strategy-game treatment. The 4x native-scale sheet was inspected; candidate art is not runtime acceptance.

Each ID has one south-facing authored view under the native catalog contract. Sources and exact initial prompts are retained. The correction requested vertically stacked blank screens on a short pedestal, near-square 26:27 silhouette and unchanged painted style.

The airlock is the new outer frame only, with a transparent center. Runtime must compose saved open/closed/jammed iris geometry through this opening. Screen faces, queue rows, planning felt and threat chamber are intentionally empty for real content or existing cosmetic animation. Physical amber trim is decorative and not evidence of live work, success or connectivity. Preserve the studio's actual image/voice success/failure triggers.

Fits are uniform and bottom-centered; no stretched or rotated upright images. The new wide displays and tables use less height than their native maximum envelopes. Use their measured fit and content regions rather than copying old artwork coordinates.
