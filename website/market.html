INSTALL IN ONE CLICK

  1. STEP 01

    Open the market

    In StarNet, open ABILITIES, then DISCOVER › SKILL MARKET. It shows this same catalog, and which skills you already have.

  2. STEP 02

    Install

    Press INSTALL. The skill joins your station's skill library, switched on for the whole crew. Skills marked BUILT IN already came with StarNet.

  3. STEP 03

    Give it gear

    Some skills use station gear, like a DISH for web research: an agent is offered the skill once that gear is placed. Crew and planning skills use the ORCHESTRATOR, which every run you start from COMMS already has.

SHARE YOUR SKILL

Wrote a skill your crew can't live without? Put it on the market. Every StarNet station can install it, with your name on it.

  1. STEP 01

    Write a SKILL.md

    What the skill is for, then the steps an agent should follow, in order. A SKILL.md from another tool works as it is. Add up to five plain-text reference files, like templates or checklists.

  2. STEP 02

    Submit it

    Sign in with your email (a free StarNet account), open SKILLS, and upload it. Pick MIT or CC BY 4.0 and the name you want credited.

  3. STEP 03

    A person reads it

    Every upload is read line by line before it is published. You see its status on the same page: waiting, approved, live, or sent back with a note saying what to change.

HOW WE KEEP IT SAFE

  • Signed. The catalog is signed with a key that never leaves StarNet's hands. Your station checks the signature against a key built into the app, and refuses a catalog that was changed, is unsigned, or is older than one it has already seen.
  • Text only. A skill is written instructions: a SKILL.md, its license, and plain-text notes. No scripts or programs are ever installed, and the app enforces that itself.
  • Scanned twice. Every skill is scanned for dangerous instructions before it is published, and your station scans it again when it installs. Every file must match its published fingerprint byte for byte.
  • Pulled when needed. If a skill turns out to be unsafe, we pull it, and every station that installed it switches it off within minutes and says why.
  • Read by a person. Skills StarNet users share are read line by line before they are published, and are held to the same scans and the same text-only rule as every other skill.
  • Credited. Community skills keep their license and ship its text. Picks adapted from open source link back to the original; shared skills carry their author's name.

STRAIGHT ANSWERS

Do skills cost anything?

No. Every skill here is free. Running one uses your model like any other task, at your provider's price.

What is the difference between a skill and a tool?

A tool is something an agent can do, like read a web page or write a file. A skill is know-how: the steps, checks and output a good job needs. Skills never add new powers; they help agents use the tools they have.

Where do the community skills come from?

Two places. Some are open-source skills, adapted by StarNet to fit the station and credited on each card with a link to the original. Others were shared by StarNet users through SHARE YOUR SKILL; their cards say so and name the author. StarNet Originals are written by StarNet.

Can I use these skills outside StarNet?

Yes. Download on any card gives you the skill as a standard Agent Skills folder (its SKILL.md, license and notes), which other tools that read SKILL.md skills can load. StarNet Originals name StarNet's own tools and gear, so they work best on a station.

Can I publish my own skill?

Yes. Submit it from your StarNet account. A person reads it, and once it is approved it goes live with the next catalog update. Skills you and your agents write in the app stay on your station until you share them.

Who owns a skill I share?

You do. You publish it under MIT or CC BY 4.0, which lets anyone use and adapt it as long as they credit you. The name is yours too: only you can send an updated version of it.
