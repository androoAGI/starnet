STARNET DOCS

// everything you need to run your station

StarNet is a local-first desktop harness: you recruit AI agents into a living pixel-art station, and the floor you build — gear, bays, belts — is real configuration the agents actually run under. These docs cover installing it, connecting a model provider, and using every system.

Which build do these docs describe? Current source. The stable installer can be one release behind while the next Windows and macOS artifacts pass signing and notarization; the homepage always labels the latest signed public version separately.
