01Getting an agent

Hit RECRUIT. Pick a class. That’s it — they walk in.

A class is a head start, not a cage: a RESEARCHER comes tuned for digging, a WRITER for drafting, an ENGINEER for code. You can re-spec anyone later from the same door.

// NOTHING IS LOCKEDThere are no levels to grind and no unlocks. A brand-new agent can use everything your station has, from minute one.

02One desk each

An agent working on a line needs a desk (a BAY). One agent per desk, one desk per agent. Want three jobs running at the same time? That’s three agents at three desks.

03Gear = powers

Furniture isn’t decoration. The right gear switches on a real ability — and one of each is enough for the entire station.

These are the exact power words the app shows when you place the gear — the palette tile, the placement toast and this table all say the same thing.

// PLACE ONE, NOT ONE EACHGear is shared. One dish, one cabinet, one databank — place it once and your whole crew draws on it. You never furnish per agent, and adding agents never means buying the station again.
// THE ONE EXCEPTIONComputers. Every agent needs their own PC at their desk — a desk without one shows NO COMPUTE and that agent cannot run.
// IF AN AGENT “CAN’T” DO SOMETHINGCheck the gear before you blame the agent. No dish = no web. No cabinet = no files. Place the thing and the ability switches on. No restart, no settings.
